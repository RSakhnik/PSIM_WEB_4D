# PSIM_WEB_4D

**Сборка:**
```bash
npm install
npm run build
```

4D-расширение Pilot Web для визуализации календарного графика строительства непосредственно на BIM-модели.

Расширение загружает график работ и привязки элементов к работам через PAPPI, связывает данные с загруженными model parts и отображает состояние модели на выбранную дату.

**Возможности:**

- интерактивная временная шкала 4D
- загрузка `WorkSchedule`, `Work_ModelID` и `KidsModelID`
- поддержка плановых `StartDate` / `FinishDate`
- поддержка фактических `ActualStartDate` / `ActualFinishDate`
- автоматический выбор набора данных по загруженной части модели
- цветовая визуализация состояния работ на выбранную дату
- базовый полупрозрачный ghost-слой для объектов model parts, участвующих в 4D
- переключатель показа/скрытия неначатых объектов
- фильтр «Только с 3D»
- выбор работы с подсветкой связанных элементов
- приближение камеры к выбранной работе
- восстановление исходного вида модели после закрытия/сброса 4D

**Стек:** Vue 3; TypeScript; ASCON Pilot Web SDK; Pilot Web 3D; Webpack Module Federation; PAPPI/SQL data source
